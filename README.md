# Little Paws

Website prototype gồm các trang Trang chủ, Nhận nuôi, Quyên góp và Liên hệ.

## Chạy thử
Mở `index.html` bằng trình duyệt hoặc bật GitHub Pages để xem website trực tuyến.

## Lưu ý
Đây là prototype HTML/CSS/JS tĩnh. Các biểu mẫu và dữ liệu demo chưa được kết nối backend; không nhập thông tin nhạy cảm.
